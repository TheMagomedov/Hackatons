# Пульс в Telegram

«Пульс» показывает карточку бизнеса, список постов и отчёты из того же backend, который обслуживает Telegram-бота. Можно добавить описание или сайт, собрать и подтвердить профиль, подключить канал, поставить задачу на подготовку, изменить текст или время поста и согласовать актуальную версию. PDF загружается через чат бота.

## Предпросмотр без ключей

```powershell
python -m app miniapp-preview
```

Откройте [http://127.0.0.1:8765/mini/](http://127.0.0.1:8765/mini/). Параметр `--port` позволяет выбрать другой порт. Данные демонстрационные и хранятся в памяти страницы. Предпросмотр не подключается к рабочей базе, Telegram или AI.

## Кнопка в Telegram

1. На хосте приложения настройте HTTPS-прокси для всего префикса `/mini/` на `http://127.0.0.1:8766/mini/`. Прокси должен сохранять путь и заголовок `X-Telegram-Init-Data`; не записывайте этот заголовок в логи. Сервер слушает loopback.
2. Добавьте в локальную конфигурацию `MINI_APP_URL=https://ваш-домен/mini/`. При необходимости измените `MINI_APP_PORT` и порт upstream на прокси. Существующие настройки бота, владельца и провайдеров используются как раньше.
3. Запустите `python -m app run`. В личном чате владельца появится кнопка «Открыть Пульс». Откройте её из Telegram. Ссылка в обычном браузере показывает страницу входа без доступа к рабочим данным.
4. Проверьте карточку и список постов. Для проверки публикации используйте тестовый канал, будущую дату и явное согласование версии.

Сервер проверяет подпись и свежесть Telegram `initData`, сопоставляет пользователя с владельцем и передаёт операции в `BackendService`. Время в форме вводится в часовом поясе устройства и передаётся в API с явным смещением UTC. Планировщик отправляет только ту версию, которую согласовал владелец.
