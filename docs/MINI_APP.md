# САЛАВАТСТЕКЛО · Mini App в Telegram

Mini App использует тот же backend и SQLite, что и бот. Пять разделов: главная, посты, задачи, отчёты, бизнес. Можно подключить компанию без кода, добавить текст/сайт/PDF, заполнить и подтвердить профиль, подключить канал, подготовить материалы и согласовать конкретную версию. Собственная модель команды подключается позже через существующий интерфейс провайдера.

Оформление соответствует выбранным элементам [брендбука САЛАВАТСТЕКЛО](BRAND.md): оригинальный логотип, петроль, фирменные паттерны и шрифты. В браузерном preview начальная тема светлая; в Telegram используется тема клиента. Кнопка смены темы доступна в шапке. Демонстрационные материалы описывают стекло и фирменный стиль; их нельзя выдавать за опубликованные компанией посты.

## Работа до подключения нейросети

1. Создайте бизнес. В разделе «Бизнес» заполните профиль вручную: описание, продукты, аудитория и тон. Сведения сохраняются как источник владельца; отдельно проверьте и подтвердите профиль.
2. Подключите канал. В рабочем режиме нужны Telegram-бот и права владельца/бота в канале; AI для проверки канала не нужен.
3. Нажмите «Создать пост», напишите текст до 900 символов и загрузите собственный PNG или JPEG. В рабочем режиме файл проверяется на сервере: до 10 МБ (или меньшего `MAX_UPLOAD_BYTES`), до 4096×4096, статичное изображение. Черновик можно сохранить без даты.
4. Проверьте текст и изображение, задайте будущее время и согласуйте актуальную версию. Ручное создание не вызывает AI, не создаёт задания генерации и не расходует квоту AI-операций. Повтор одного запроса создания возвращает тот же пост даже после перезапуска сервера.
5. Откройте «Посты»: поиск по тексту, фильтры статуса, список и календарь. Календарь группирует материалы по датам в часовом поясе компании; посты без даты остаются в списке. Замена изображения, изменение текста или времени снимают согласование.

Кнопка «С AI» отделена от ручного создания. При отсутствии провайдера интерфейс сообщает об этом и предлагает ручной сценарий. Состояние «настроен» означает наличие адаптера в конфигурации, а не проверенные ключи, баланс или доступность сервиса. Модель команды должна реализовать `AIProvider` в `app/shared/ports.py` и быть подключена через `AI_PROVIDER_FACTORY`; для генерации изображений предусмотрен отдельный `ImageProvider`. Интерфейс Mini App и правила согласования при этом сохраняются.

В «Задачах» доступны диалог с историей компании, очередь, отмена ожидающего задания, расписание автономной подготовки, пауза публикаций и журнал AI-операций. Пауза отправок не выключает подготовку. Каждый новый черновик остаётся неодобренным.

Предпросмотр поста показывает текст, изображение, канал, время, версию, источники и предупреждения. Ручные и AI-правки снимают прежнее согласование. Если профиль изменился, нужно пересмотреть материал в новом контексте и согласовать новую версию. Неизвестный результат доставки требует проверки канала через бот, автоматического повтора нет.

## Предпросмотр без ключей

```bash
python -m app miniapp-preview
```

Откройте [http://127.0.0.1:8765/mini/](http://127.0.0.1:8765/mini/). `--port` задаёт другой порт. Баннер «Демо» сообщает об имитации: AI и внешних публикаций нет. Компании, черновики, задания и история сохраняются в `localStorage` этого браузера под ключом `salavatsteklo.preview.v1`; изображения для демо ограничены 1 МБ. «Сбросить» возвращает исходные примеры. Прежний ключ `tirazh.preview.v1` не импортируется и не удаляется: данные предыдущего оформления остаются нетронутыми. При недоступном хранилище интерфейс предупреждает, что изменения останутся только в текущей вкладке. Это интерфейсный предпросмотр, не доказательство live-сценария.

Рабочие данные хранятся в SQLite и каталоге файлов сервера. Демо-хранилище в рабочем режиме не читается и не записывается; Telegram-подпись и токены в него не попадают. Сетевые запросы ограничены по времени и автоматически не повторяются: после таймаута сохранения проверьте состояние поста/задания перед новым действием.

## Запуск с ботом на обычном хосте

Для запуска на компьютере с временным HTTPS-туннелем используйте [пошаговую инструкцию LOCAL_RUN](LOCAL_RUN.md). Проверенный в Telegram запуск, сохранение компании и профиля описаны в [журнале проверок](VALIDATION.md); публикация в настоящий канал пока не проверена.

1. Подготовьте `.env` из `.env.live.example`, заполните настройки владельца, Telegram и выбранных провайдеров.
2. Настройте HTTPS reverse proxy для всего `/mini/` на `http://127.0.0.1:8766/mini/`. Сохраняйте полный путь и заголовок `X-Telegram-Init-Data`; не записывайте этот заголовок в логи.
3. Укажите `MINI_APP_URL=https://ваш-домен/mini/`. По умолчанию сервер слушает `127.0.0.1`; если меняете `MINI_APP_PORT`, обновите upstream.
4. Запустите `python -m app run`, откройте `/start` в личном чате владельца, затем меню «Открыть студию».

Обычный браузер без Telegram-подписи не получает доступ к рабочим данным. Подпись ограничена одним часом: при истечении закройте и снова откройте Mini App из бота. Время редактирования вводится в часовом поясе устройства и отправляется с UTC-смещением; в карточке выводится часовой пояс компании.

## Сервер с Docker и автоматическим HTTPS

Домен должен указывать на сервер; порты 80/443 должны быть доступны. В `.env`:

```dotenv
MINI_APP_DOMAIN=marketer.example.com
MINI_APP_URL=https://marketer.example.com/mini/
```

Замените пример настоящим доменом, затем:

```bash
docker compose -f compose.yaml -f compose.https.yaml config --quiet
docker compose -f compose.yaml -f compose.https.yaml up --build -d
docker compose -f compose.yaml -f compose.https.yaml logs --tail=50
```

`compose.yaml` слушает `0.0.0.0:8766` **внутри контейнера**, а наружу отдаёт порт только на loopback хоста. Caddy обращается к `marketer:8766` по внутренней сети. Сертификаты сохраняются в volumes, префикс `/mini/` не отрезается. HTTP access log по умолчанию отключён в приложении; Caddyfile не включает access logging. [Документация Caddy reverse proxy](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy) и [объединение Compose-файлов](https://docs.docker.com/compose/how-tos/multiple-compose-files/merge/).

Для текстового режима аккаунта ChatGPT добавьте `-f compose.chatgpt.yaml` и предварительно выполните [серверный вход](CHATGPT_CONNECTION.md). Изображения всё равно требуют настройки отдельного провайдера.

`/mini/health` сообщает только состояние HTTP и режим приложения, без токенов и клиентских данных. Он не доказывает доступность Telegram или AI. Финальная проверка — [живой сценарий защиты](DEMO_SCRIPT.md).

## Проверки интерфейса

```bash
npm ci
npx playwright install chromium
python -m app miniapp-preview
# В другом терминале:
npm run test:ui
npm run test:ui:unit
npm run test:ui:content
npm run test:ui:a11y
npm run test:ui:backend
```

UI-проверки охватывают узкие и широкие экраны, обе темы, оригинальные логотипы и их охранное поле, фактическую загрузку фирменных шрифтов, клавиатуру, формы, ручной редактор, календарь, поиск, восстановление демо, создание второй компании, разделение истории, расписание, паузу и повторное согласование. Backend/API тесты запускаются через `pytest`; они используют подписанные тестовые Telegram-данные и настоящую SQLite, без отправки сообщений в Telegram. Отдельный ручной цикл проверяется с ненастроенными AI-провайдерами.
