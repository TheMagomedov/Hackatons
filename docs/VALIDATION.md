Браузерный backend fixture не загружает `.env`, создаёт временную базу и не запускает публикационный worker. Он проверяет проводку UI/API, а не доступ к Telegram. На демонстрационных экранах есть явная маркировка режима. Согласование в UI недоступно, пока изображение не загрузилось.

Ручной API-путь проверен с `APP_MODE=live`, подписанной тестовой Telegram-сессией, настоящей SQLite и файлами, `UnconfiguredAI` и `UnconfiguredImages`: профиль → подтверждение → канал → PNG/JPEG → черновик → согласование → одна имитированная отправка. Число AI-операций остаётся 0. Дополнительно проверены дедупликация после повторного открытия базы, чужие изображения/источники, повреждённые и слишком большие картинки, устаревшие версии, изменение картинки после согласования, прошедшее время и запрет demo-файлов в live.

В этом раунде работа сосредоточена на Mini App: живых запросов к нейросетям не выполнялось. Историческая проверка аккаунта ChatGPT выше относится к предыдущему интеграционному прогону; собственная модель команды подключается отдельно. Браузерные проверки не заменяют проверку настоящего Telegram WebView и экранной клавиатуры телефона.

## Что остаётся подтвердить с доступами команды

1. Реальную генерацию изображения выбранным провайдером и реальные права бота в тестовом канале.
2. Публикацию согласованного материала в этом канале с сохранением ссылки и уведомлением.
3. Публичный HTTPS-домен, запуск на сервере после выключения ноутбука и серверную авторизацию ChatGPT, если выбран этот режим.
4. Живую автономную подготовку по расписанию и продолжение диалога после серверного перезапуска.

Отдельные клиентские роли, VK/MAX, мониторинг комментариев и функции конечного коммерческого продукта перечислены в [матрице ТЗ](BRIEF_COMPLIANCE.md). Успешные локальные тесты не означают, что эти функции уже реализованы.

Для воспроизведения UI-проверок: `npm ci`, `npx playwright install chromium`; preview-сервер нужен только для `test:ui`. `test:ui:backend` сам запускает fixture; если Python не активирован в PATH, задайте `PYTHON_EXECUTABLE` с путём к виртуальному окружению.
