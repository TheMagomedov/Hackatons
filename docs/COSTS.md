# Оценка расходов одного AI-маркетолога

Это расчёт при заданной нагрузке, не счёт провайдера и не обещание фиксированной цены. Квота операций в интерфейсе ограничивает количество логических действий; деньги и токены она не измеряет.

## Текущий этап: Mini App без модели

Ручные профиль, загрузка изображения, редактор, календарь и согласование не вызывают нейросеть. Покупка AI API для разработки и проверки этого сценария не нужна. Локальный preview также не обращается к AI и не публикует посты.

Модель у команды уже есть; её стоимость и ограничения нужно считать после передачи способа подключения, оборудования и измеренных задержек. Хостинг Mini App, хранение изображений, домен и резервные копии учитываются отдельно.

## Шаблон расчёта после интеграции

Для сопоставимого замера можно принять 30 постов в месяц, 39 изображений с учётом переделок, 300 000 входных и 60 000 выходных текстовых токенов. Это тестовая нагрузка, а не прогноз фактического потребления.

| Статья | Что измерить или запросить у команды |
| --- | --- |
| Текст через API | Входные/выходные токены и действующие тарифы выбранной модели |
| Свой сервер модели | Часы CPU/GPU, память, хранение весов, электричество или аренда |
| Изображения | Число генераций и переделок, размер, качество, стоимость одной генерации |
| Приложение | Сервер, диск, резервные копии, домен |
| Эксплуатация | Налоги, комиссии, мониторинг и работа оператора |

Для API итог считается формулой:

`text_input_tokens / 1e6 × input_price + text_output_tokens / 1e6 × output_price + image_generation_cost + image_input_cost + hosting + backups`.

Прежний расчёт на конкретных моделях удалён: он не отражает выбранную командой модель и не должен использоваться как актуальное предложение провайдера. Перед защитой запишите модель, дату проверки тарифов, измеренную нагрузку и стоимость фактического прогона.

## Режим аккаунта ChatGPT

Текст использует доступ и ограничения подключённого аккаунта через официальный Codex CLI. Нельзя объявлять это бесплатным безлимитным API: стоимость подписки и доступность нужно подтвердить для выбранного аккаунта. Изображения и сервер оплачиваются отдельно. Учёт backend остаётся учётом операций, не биллингом подписки.

## Как ограничить расходы

Для демонстрации: `MAX_POSTS_PER_JOB=1`, `MAX_PENDING_JOBS=3`, `MAX_GENERATION_JOBS_PER_DAY=5`, `MAX_AI_OPERATIONS_PER_DAY=30`, `MAX_CONCURRENT_AI_OPERATIONS=1`. Добавьте лимиты расходов у API-провайдера. При переносе из демо в live ограничьте автоматическую подготовку до одного запуска в сутки; после проверки увеличьте частоту через интерфейс.
