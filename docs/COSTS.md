# Оценка расходов одного AI-маркетолога

Это расчёт при заданной нагрузке, не счёт провайдера и не обещание фиксированной цены. Квота операций в интерфейсе ограничивает количество логических действий; деньги и токены она не измеряет.

## Пример для API-режима

Предположим 30 постов в месяц, 39 изображений с учётом девяти переделок, суммарно 300 000 входных и 60 000 выходных текстовых токенов для профиля, планирования, диалога и правок. Сервер за $8/месяц и резервное хранение за $2/месяц — **бюджетные допущения**, не найденные тарифы или рекомендация поставщика.

| Статья | Формула | USD/месяц |
| --- | --- | ---: |
| Текст GPT-4.1 mini | 0,3 × $0,40 + 0,06 × $1,60 | 0,216 |
| 39 изображений GPT Image 1, 1024×1024, medium | 39 × $0,042 | 1,638 |
| Либо те же изображения, high | 39 × $0,167 | 6,513 |
| Сервер + резервные копии (допущение) | $8 + $2 | 10,00 |
| Всего с medium | $0,216 + $1,638 + $10 | **11,854** |
| Всего с high | $0,216 + $6,513 + $10 | **16,729** |

Входные токены графической модели, налог, домен, повторные обращения, комиссии и работа оператора добавляются отдельно. Текущий адаптер изображения не фиксирует quality/size: провайдер выбирает их автоматически. Поэтому пример medium — сценарий оценки, не точное отражение выставленного счёта. Для защиты разумно показать диапазон **$12–17 плюс указанные дополнительные расходы** при этой нагрузке; коммерческую цену услуги считать отдельно.

Вычисляйте реальную стоимость формулой:

`text_input_tokens / 1e6 × input_price + text_output_tokens / 1e6 × output_price + image_generation_cost + image_input_cost + hosting + backups`.

Цена текста подтверждена [страницей GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), цены выходных изображений — [страницей GPT Image 1](https://developers.openai.com/api/docs/models/gpt-image-1). Проверено 13.11.2026; перед коммерческим расчётом перепроверьте тарифы.

## Режим аккаунта ChatGPT

Текст использует доступ и ограничения подключённого аккаунта через официальный Codex CLI. Нельзя объявлять это бесплатным безлимитным API: стоимость подписки и доступность нужно подтвердить для выбранного аккаунта. Изображения и сервер оплачиваются отдельно. Учёт backend остаётся учётом операций, не биллингом подписки.

## Как ограничить расходы

Для демонстрации: `MAX_POSTS_PER_JOB=1`, `MAX_PENDING_JOBS=3`, `MAX_GENERATION_JOBS_PER_DAY=5`, `MAX_AI_OPERATIONS_PER_DAY=30`, `MAX_CONCURRENT_AI_OPERATIONS=1`. Добавьте лимиты расходов у API-провайдера. При переносе из демо в live ограничьте автоматическую подготовку до одного запуска в сутки; после проверки увеличьте частоту через интерфейс.
