# Проверки MVP

`python -m pytest -q` запускает автоматические проверки. Тесты используют временную SQLite, тестовые AI-ответы и перехваченные Telegram-методы. `python -m app --demo` повторяет сквозной сценарий без сети. Значения в тестовых отчётах берутся из сохранённых тестовых событий.

| Сценарий | Ожидаемый результат | Где проверить |
| --- | --- | --- |
| PDF с текстом и PDF без текстового слоя | Текст извлечён. Для скана бот просит текстовый PDF | `test_ai.py`, AI |
| URL внутреннего адреса | Загрузка отклонена до обращения к адресу | `test_ai.py`, AI |
| Спрятанная инструкция, неизвестная цена, конфликт источников | Источник передан как данные, профиль связывает факты с источниками, пробел и вопрос показаны отдельно | `test_ai.py` проверяет контракт. Дополнительно прогнать на выбранной модели, AI |
| Неверный ответ модели или отказ в доступе | Не больше двух попыток разбора. Ошибка доступа показывается сразу | `test_ai.py`, AI |
| Ошибка картинки | Повреждённое изображение отклоняется. Неудачная правка сохраняет прежнюю версию | `test_reports_media.py`, Media; вручную с отключённой моделью |
| Чужой пользователь, старая кнопка, двойной клик | Доступ закрыт, старая версия отклонена, очередь содержит одно задание | `test_workflow.py`, `test_telegram.py`, Backend/Telegram |
| Правка, смена канала, просроченное время | Новые условия требуют согласования. Просроченный черновик нужно перепланировать | `test_workflow.py`, Backend |
| Перезапуск и потеря ответа на отправку | Согласованные задачи сохраняются. Неизвестная доставка проверяется вручную | `test_workflow.py`, Backend |
| Автоподготовка, повторный тик, выключение | Один запуск на период, только черновики. Выключение останавливает новые циклы | `test_workflow.py`, Backend |
| Нет реакций или начального снимка подписчиков | «Нет данных» отличается от измеренного нуля. Для реакций используется последний снимок | `test_reports_media.py`, `test_telegram.py`, Analytics |
| Живой прогон | Бот получает обновления и публикует согласованную версию в тестовый канал. При наличии доступа AI генерирует текст и изображение | Тестовый бот, канал и AI-ключ, все роли |

## Показ на защите

1. Подключите приватный тестовый канал и приготовьте короткий PDF с текстом меню. В отдельном окне держите открытыми бот и канал. Для запуска с тестовыми материалами используйте «Загрузить пример кофейни».
2. Соберите карточку «Тёплое зерно». Покажите ссылки на источники, пожелания к стилю и неизвестные цены. Подтвердите карточку и попросите три поста на неделю о завтраках.
3. Подготовьте материалы, откройте фото и попросите сократить текст. Нажмите кнопку согласования из предыдущего предпросмотра, чтобы показать проверку версии.
4. Выберите ближайшее будущее время с часовым поясом и согласуйте новый вариант. Откройте уведомление и сообщение в канале.
5. Покажите отчёт. Если Telegram ещё не прислал реакции, покажите статус «нет данных». Включите автоподготовку и покажите время следующего цикла.
6. Запишите этот прогон после подключения внешних сервисов. Резервное видео `demo-offline.mp4` показывает фактический вывод локального сценария с тестовыми адаптерами.

Правила хакатона по обязательным площадкам нужно проверить отдельно. MVP использует один бизнес и Telegram.
