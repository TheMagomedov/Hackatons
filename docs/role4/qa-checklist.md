# Общая проверка MVP

Владелец координации — роль 4. Успешные результаты записываются только после
фактической проверки. Сейчас это сценарии для будущей интеграции.

| Сценарий | Ожидаемый результат | Участники |
| --- | --- | --- |
| Сайт и PDF с текстом | Профиль со ссылками на подтверждённые факты | 1, 2, 3 |
| PDF без текста | Понятная ошибка без ложного успеха | 1, 3 |
| Запрос трёх постов | План с разными темами; одобрение плана разрешает подготовку | 1, 2, 3 |
| Подготовка поста | Текст и одно реальное изображение той же версии | 1, 2, 4 |
| Локальный AI → изображение → отчёт | После проверки локального режима сохраняются source IDs, image_brief, точные байты и demo-разделение; офлайн mock не выдаётся за проверку качества модели | 1, 2, 4 |
| Фирменная карточка → модерация → хранение | Проверены и сохранены одни и те же итоговые байты; полный кадр и исходный логотип сохранены | 2, 4 |
| Явный локальный FLUX → фирменная карточка → отчёт | Только opt-in, точные loopback/model; без выбранной модели генерации нет; офлайн транспорт подтверждает байты, feedback и снятие согласования | 2, 4 |
| Reviewer: картинка и отчёт | Просмотр и скачивание доступны, изменения и генерация запрещены до обращения к провайдеру | 2, 3, 4 |
| Live-настройки под обёртками | Отсутствующие настройки остаются видны в capabilities; интерфейс не предлагает недоступную генерацию | 1, 2, 3, 4 |
| Предел ручной загрузки | Заявленный интерфейсом размер учитывает ограничения включённой модерации | 2, 3, 4 |
| Windows: адрес генератора | Проверка запуска принимает только адрес, совместимый с реальной фабрикой изображений | 2, 4 |
| Windows: пользовательский Caddyfile | Проверяются также маршруты обработки ошибок и завершающий 404; чужие сервисы не получают разрешения обходом основного списка routes | 2, 4 |
| Отказ или таймаут API | Понятный статус; бот продолжает отвечать; нет скрытой подмены demo | 2, 3, 4 |
| Неизвестная цена | Ни текст, ни задание изображения не утверждают придуманную цену | 1, 4 |
| Правка текста или картинки | Новая версия backend и повторное согласование | 1, 2, 3, 4 |
| Долгая правка картинки согласованного поста | Сразу `editing` без согласования; старый вариант не публикуется; отчёт показывает «редактируются» | 2, 3, 4 |
| Ошибка или отмена AI-правки | `failed` без восстановления старого согласования; новая попытка только отдельным запросом | 1, 2, 3, 4 |
| Замена канала или времени | Старое согласование не разрешает новую публикацию | 2, 3 |
| Время с часовым поясом | Backend проверяет дату, отчёт учитывает точные границы периода | 2, 4 |
| Публикация по расписанию | Только отдельно согласованный текст, изображение, канал и время | 2, 3 |
| Повтор задания публикации | Нет повторного поста после успешной публикации | 2 |
| Пустой отчёт | Честные нулевые счётчики и недоступные внешние метрики | 2, 3, 4 |
| Частичные метрики | Сумма только известных значений и явное покрытие | 2, 4 |
| Демонстрационные данные | Отметка demo; данные исключены из реальной статистики | 2, 3, 4 |
| Mini App: квадратный/вертикальный кадр | В согласовании видна полная картинка либо доступен оригинал | 3, 4 |
| Mini App: ошибка загрузки картинки | Видимая ошибка и повтор загрузки; согласование недоступно до показа изображения | 3, 4 |
| Mini App: внешний SDK задержан | Подписанная сессия открывает интерфейс и изображение; поздний SDK не повторяет запросы, неподписанные и поддельные данные доступа не дают | 2, 3, 4 |
| Mini App: график и полный отчёт | Одинаковый период и demo-разделение; события вне `[start,end]` исключены до группировки по датам | 2, 3, 4 |
| Mini App: ручной черновик без AI | Создание входит в реальные данные отчёта; публикаций и AI-операций 0; неизвестные реакции остаются неизвестными | 2, 3, 4 |
| Preview: загруженная картинка → AI-правка | Демонстрация показывает изменённую иллюстрацию, новую версию и снятое согласование; после перезагрузки остаётся новый вариант | 3, 4 |
| Большой ручной профиль → AI-подготовка | До обращения к провайдеру проверяется пригодность контекста для лимитов текста/изображений | 1, 2, 4 |
| Mini App: фоновое изменение поста | Возврат на главную обновляет статусы и счётчики; режим preview и demo-посты различимы во всех разделах | 3, 4 |
| Mini App: создание/смена компании при медленном ответе | Старые действия недоступны до нового состояния; после ошибки есть повтор; ручной профиль сохраняется в выбранную компанию | 3, 4 |
| Автономная подготовка | Новые черновики по расписанию без самовольной публикации | 1, 2, 3, 4 |
| Скрытые инструкции источника | Данные бизнеса не управляют правами приложения | 1, 2 |

Автотесты роли 4 проверяют границы своих модулей. Сквозные сценарии требуют
единого приложения и тестового Telegram-канала. Доступность просмотров,
реакций и иных показателей определяется фактически подключённым источником;
их наличие не следует обещать только по наличию Telegram-бота.
