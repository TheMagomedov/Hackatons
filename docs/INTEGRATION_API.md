# API студии для ботов и интеграций

Владелец открывает **Бизнес → API для интеграций → Управлять API-ключами**. Ключ привязан к одной компании, действует 1–90 дней и показывается один раз. В базе хранится SHA-256, исходный ключ восстановить нельзя. Отзыв действует сразу. Архивирование компании блокирует её ключи, восстановление backup отзывает все ключи из снимка.

Базовый адрес — публичный адрес приложения с путём `/mini/integration/v1`. Для текущей установки это `https://176.115.139.80/mini/integration/v1`. Передавайте ключ в заголовке `Authorization: Bearer <ключ>` с вашего сервера. Не помещайте его в URL, frontend, журнал запросов или Git.

| Метод и путь | Право | Результат |
| --- | --- | --- |
| GET `/me` | read | ID и название компании |
| POST `/images` | generate | 202: сохраняемое задание изображения |
| POST `/prepare` | generate | 202: задание поста с текстом и изображением |
| GET `/jobs/{id}` | read | Статус, этапы и готовый `visual_result` для изображения |
| GET `/posts` | read | Последние 100 постов компании |
| GET `/assets/{id}` | read | PNG/JPEG результата |

Для обоих POST передайте JSON `{"request":"Стеклянный фасад в сосновом лесу","request_id":"unique-client-request-1"}`. `/images` дополнительно принимает `caption` до 900 символов, чтобы подобрать картинку по готовому тексту. `request_id` должен оставаться одинаковым при повторе одного запроса. Изменение содержания при том же ID возвращает конфликт, а повтор того же задания не запускает новую генерацию. Длина ID — до 100 символов, запроса — до 4000.

Опрашивайте `/jobs/{id}` не чаще раза в 3 секунды. Статусы: `pending`, `running`, `done`, `failed`, `cancelled`. При `done` у изображения файл находится по `visual_result.asset.id`. Запросы создания могут исчерпать лимит очереди или AI-операций; новая попытка с другим ID считается отдельным действием.

Ограничение — 60 запросов в минуту на ключ (HTTP 429). Недействительный, истёкший, отозванный ключ или доступ к другой компании дают HTTP 403. Ошибки содержат безопасное сообщение в поле `error`. Секреты внешнего AI и Telegram через этот API не возвращаются.

Ключи не могут согласовывать и отправлять публикации. Материалы проверяет оператор в студии. Поле `daily_limit` в настройке **Лимит AI компании** ограничивает логические действия за сутки UTC: 0 блокирует новые операции, пустое значение сохраняет общий лимит владельца. Это не денежный бюджет и не расчёт стоимости модели.
