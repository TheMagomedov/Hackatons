# Тексты через AgentRouter

Тексты, ответы по документам и контент-планы используют AgentRouter через
настоящий Codex CLI с отдельным API-ключом. Это внешний провайдер: очищенный текст
и необходимые материалы компании отправляются AgentRouter. FLUX, переводчик,
модерация, индекс документов, база и кеш остаются на ПК. Qwen/Ollama не запускается.

Локальный `.env` (ключи и пути установки не добавлять в Git):

```dotenv
AI_PROVIDER_FACTORY=app.ai.agentrouter:build_provider
CODEX_CLI_PATH=C:/path/to/native/codex.exe
TEXT_API_BASE=https://agentrouter.org/v1
TEXT_API_KEY=
TEXT_MODEL=gpt-6.1-sol
TEXT_WIRE_API=responses
TEXT_REASONING_EFFORT=low
TEXT_TIMEOUT_SECONDS=120
TEXT_MAX_RETRIES=0
AI_CACHE_TTL_SECONDS=900
```

Нужен нативный CLI **0.167.0-alpha.4.1**, проверенный на этом Windows-ПК.
Неизвестная версия блокируется до обращения к провайдеру. После обновления CLI
сначала повторите локальную проверку ниже, затем обновите allowlist в адаптере.
На Windows `.cmd`/`.ps1`-обёртки не поддерживаются. Bootstrap проверяет путь
`CODEX_CLI_PATH` и передаёт его только дочернему процессу.

## Как устроено подключение

У AgentRouter есть [документированный способ подключения Codex](https://github.com/agentrouter-org/docs/blob/main/codex.md).
Прямой Python HTTP-запрос с этим ключом возвращал 401 `unauthorized_client_error`.
Адаптер использует настоящий CLI с API-ключом, без подмены идентичности клиента.
Вход в ChatGPT и подписка пользователя для этого пути не используются.

Для каждого вызова создаются пустые рабочая папка и `CODEX_HOME`. Личная
конфигурация, авторизация, правила, история и подключённые приложения не загружаются.
Ключ передаётся через окружение; в аргументах, промпте, временных файлах и логах
ключа нет. Telegram/VK/image-ключи не наследуются. Адрес провайдера ограничен
`https://agentrouter.org/v1`.

Перед запросом работают фильтр входа и маскировка распознаваемых персональных
данных/секретов. Это эвристическая защита. Системная инструкция задаётся сервером.
Shell, браузер, управление компьютером, поиск, изображения, память, плагины,
skills и MCP-инструменты текстовой модели отключены. Это не отменяет серверные
инструменты приложения и отдельное согласование публикаций. Локальная проверка
подтверждает отсутствие инструментов в настоящем запросе CLI.

CLI запрашивает Responses с JSON-схемой, `store:false` и `reasoning.effort=low`.
Принимается один текстовый ответ с `turn.completed` и успешным кодом процесса.
Ошибки, неполные ответы, вызовы инструментов, неверный JSON и неподтверждённые
числовые утверждения отклоняются проверками Pydantic/ModelAI. Модерация сохраняется.

Ограничены время вызова и размер вывода. Тайм-аут, отмена и завершение backend
останавливают принадлежащее запросу дерево процессов (Windows Job Object),
временный каталог удаляется. Повторных сетевых попыток внутри CLI нет;
`TEXT_MAX_RETRIES` для этого транспорта принудительно равен нулю.

Кеш разделён по компании, версии профиля, модели, адресу, транспорту, схеме,
системной инструкции и настройке рассуждения. Трейсы содержат метаданные без
промптов, ключей и заголовков. Замены на Qwen, другую модель или аккаунт нет.

## Проверки

Локальная проверка настоящего CLI использует только фиктивный ключ и loopback,
не читает `.env` и не обращается к AgentRouter:

```powershell
.venv/Scripts/python.exe scripts/check_agentrouter_cli.py --codex C:/path/to/native/codex.exe
```

Она проверяет `/v1/responses`, Authorization, модель, `low`, `store:false`,
JSON-схему, системную инструкцию и пустой список инструментов. Это проверка
контракта, а не доказательство доступности внешнего сервиса.

Живая проверка 14.11.2026: AgentRouter через CLI вернул JSON `{"ok":true}` за
8,59 с. Проверен ответ по настоящим выдержкам брендбука: Intro Black и Avenir
Next Cyr с указанием источника (31,03 с), план одного поста (31,41 с), текст
(33,56 с) и правка текста (57,00 с). Все ответы прошли схемы и проверки источников.
Полный pytest: 1013 passed, 5 skipped, 226 subtests; Ruff пройден.
Результаты проверки не добавляются в рабочие
посты автоматически. При сбое провайдера приложение не выдаёт шаблонный текст.

Прямой HTTP-адаптер `app.ai.provider:build_provider` остаётся отдельным явным
вариантом для сервисов, разрешающих такой доступ. Автоматического переключения
между ним, CLI, локальной моделью и аккаунтом ChatGPT нет.

Настройки CLI: [официальная документация OpenAI](https://developers.openai.com/codex/config-reference).
