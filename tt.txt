**ComfyUI + Flux можно оставить. Tailscale тоже подходит, но текущий проект нужно доработать, чтобы организаторы могли пользоваться им со своих Telegram-аккаунтов.** Я проверил публичную ветку `main` репозитория.

Tailscale — это средство сетевого доступа. Сайт `console.tailscale.com/admin/machines` управляет подключёнными компьютерами; изображения генерирует ComfyUI на твоём компьютере или сервере.

Что нужно исправить:

1. **Подключить настоящий API ComfyUI.** Сейчас [адаптер изображений](https://github.com/TheMagomedov/Hackatons/blob/main/app/media/runtime.py#L24) отправляет запросы на `/images/generations` и ожидает ответ в формате OpenAI. Обычный ComfyUI работает иначе: backend отправляет workflow через `POST /prompt`, ждёт выполнения и забирает изображение через `/history/{prompt_id}` и `/view`. Поэтому просто вставить твою ссылку в `IMAGE_API_BASE` недостаточно. Нужен отдельный адаптер ComfyUI и твой workflow, экспортированный **в API-формате**. Это описано в [документации ComfyUI](https://docs.comfy.org/development/comfyui-server/comms_routes).

2. **Разрешить доступ организаторам.** Сейчас [Mini App](https://github.com/TheMagomedov/Hackatons/blob/main/app/miniapp/server.py#L145), бот и backend допускают только `OWNER_TELEGRAM_ID`. Другие пользователи получат отказ. Нужно добавить доступы к тестовой компании, сохранив проверку авторизации Telegram и разграничение данных.

3. **Обеспечить публичный HTTPS-адрес самого Mini App.** [Tailscale Serve](https://tailscale.com/kb/1312/serve) даёт доступ внутри сети Tailscale, а [Funnel](https://tailscale.com/kb/1223/funnel) позволяет обращаться из интернета без установки Tailscale. Для демонстрации можно публиковать через Funnel backend приложения на порту `8766`. В `MINI_APP_URL` должен быть адрес вида `https://твой-домен/mini/`. Переданная ссылка с `?workflows=Flux…` открывает интерфейс генератора и не заменяет адрес Mini App.

Рекомендую такую схему:

```text
Организатор → Telegram Mini App → публичный backend
                                     ├─ GPT API — текст
                                     └─ ComfyUI + Flux — картинки
```

Если backend и ComfyUI находятся на разных машинах, **между ними можно оставить приватное соединение Tailscale**. Организаторам тогда нужен только Telegram. Ключи провайдеров хранятся на backend.

Есть ещё два требования из приложенного ТЗ :codex-file-citation{path="C:/Users/123/Downloads/doc-1794511527.pdf" purpose="source"}:

- **Работа 24/7 без включённого компьютера администратора.** Домашний ПК с ComfyUI подходит для демонстрации, пока он работает. Для выполнения этого требования понадобится постоянно доступный GPU-сервер либо внешний API генерации. Обычный VPS для backend сам по себе проблему генерации не решит.
- **Подтверждение использования существующего аккаунта ChatGPT.** Один GPT API-ключ этот критерий не подтверждает. В репозитории есть отдельный адаптер через Codex CLI, но его авторизацию и работу на твоём сервере я не проверял.

При проверке `lsrx.tail33164d.ts.net` из моей среды домен не разрешился, поэтому публичную доступность я пока не подтвердил. **Менять Flux сейчас оснований нет: сначала нужно подключить ComfyUI к backend, настроить доступы пользователей и публичный адрес Mini App.**
