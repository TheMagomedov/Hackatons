# Приватный FLUX gateway

Воспроизводимый исходный код HTTP-адаптера для существующей установки FLUX. Включены gateway, его изолированные тесты, небольшой ComfyUI-клиент и фиксированный граф. Это **не готовая установка всей AI-системы**: ComfyUI, расширение серверной модерации, локальные переводчик и модератор, их модели и окружения разворачиваются отдельно. Никакие веса, ключи, `.env`, пользовательские изображения или история не входят в этот каталог.

## Состав и запуск адаптера

```text
flux_gateway/
  flux_api.py                  # translate → submit once → wait → PNG
  generate.py                  # ограниченный HTTP-клиент ComfyUI
  flux_4070ti_api.json          # фиксированный граф FLUX.1 Dev
  image_api/
    image_api_server.py        # loopback HTTP 8193
    test_image_api_server.py   # mock backend/helper, настоящая локальная HTTP-граница
    api_key.txt               # создаёт оператор; отсутствует в Git
  requirements.txt
  config.example.env          # пример отдельных окружений gateway и backend Mini App
```

Проверено с Python 3.12 и Pillow 13.0.0. Из корня этого каталога:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B image_api\test_image_api_server.py
```

Тесты используют публичную тестовую строку вместо настоящего ключа и не обращаются к GPU, Telegram, ComfyUI или модератору. Не путайте прохождение этих тестов с проверкой готовности отдельной GPU-установки.

Для запуска оператор указывает уже существующий локальный файл через `FLUX_GATEWAY_KEY_FILE` либо отдельно создаёт `image_api/api_key.txt` с криптографически случайным ключом: минимум 32 ASCII-символа без пробелов; подходят 32 случайных байта, закодированных hex/base64url. Не вводите значение в код, URL, frontend или командную строку. Защитите файл правами владельца. `.gitignore` исключает стандартный `api_key.txt`, но не заменяет проверку состава коммита. Без существующего файла с валидным ключом процесс завершится **до открытия порта и загрузки backend**. Путь и содержимое файла не включаются в ошибку. Ротация требует перезапуска только gateway.

```powershell
.\.venv\Scripts\python.exe -B image_api\image_api_server.py
```

Процесс слушает **только `127.0.0.1`**, порт по умолчанию 8193. Он не запускает и не останавливает зависимые сервисы, не устанавливает модели, не меняет firewall или Tailscale. Относительное расположение трёх клиентских файлов над `image_api/` обязательно: `load_backend()` импортирует именно их. При переносе к существующему `Flux_4070Ti_Starter` сохраняйте ту же структуру.

Параметры gateway читаются из окружения процесса, а не автоматически из файла примера:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FLUX_GATEWAY_PORT` | `8193` | Порт 1024–65535; адрес bind всегда 127.0.0.1 |
| `FLUX_GATEWAY_HOSTNAME` | пусто | Принимаются только loopback Host; для приватного proxy укажите свой `*.ts.net` без схемы, порта и пути |
| `FLUX_GATEWAY_PREFIX` | `/flux-api` | Дополнительный путь proxy; например `/flux-demo-api`; пусто отключает префикс |
| `FLUX_GATEWAY_KEY_FILE` | `image_api/api_key.txt` | Существующий файл ключа; для внешнего файла рекомендуется абсолютный путь |

Для отдельного экземпляра рядом с работающим 8193 можно выбрать `FLUX_GATEWAY_PORT=8194` и `FLUX_GATEWAY_PREFIX=/flux-demo-api`, указать существующий файл ключа и свой hostname. Приватный Tailscale Serve тогда направляет `/flux-demo-api/` в `127.0.0.1:8194`. Этот код не останавливает прежний gateway. Ключ можно прочитать из его существующего файла, не копируя его в репозиторий. В исходниках пакета нет hostname оператора или абсолютного пути его Windows-профиля.

## Обязательные внешние зависимости

| Компонент | Адрес / проверка | Требование |
|---|---|---|
| ComfyUI | `http://127.0.0.1:8188` | Стандартные `/prompt`, `/queue`, `/history/{id}`, `/view`, `/object_info`, `/system_stats` |
| Guard в ComfyUI | `/flux-safety/health` → `active:true, ready:true` | Реальная блокировка `/prompt` и `/api/prompt`, allowlist графа, проверка всего batch перед SaveImage, отключённые непроверенные previews |
| Переводчик | `http://127.0.0.1:8190/flux-translate/translate` | POST `{text}` → `{text}`; локальный RU→EN Argos ru-en 1.9 через CTranslate2/SentencePiece; оригинал проверяется до перевода |
| Модератор | `http://127.0.0.1:8192` | `/health` с `service:flux-safety, ready:true`; контракт ниже; ошибки и занятость не должны разрешать материал |
| Приватный HTTPS | Tailscale Serve выбранного префикса → выбранный loopback-порт gateway | Сохранить Authorization; разрешённый Host задаётся `FLUX_GATEWAY_HOSTNAME`; при смене tailnet обновить окружение |

Граф требует `UnetLoaderGGUF` из совместимой установки ComfyUI-GGUF и стандартные `DualCLIPLoader`, `VAELoader`, `CLIPTextEncode`, `FluxGuidance`, `ConditioningZeroOut`, `EmptySD3LatentImage`, `KSampler`, `VAEDecode`, `SaveImage`. Имена файлов моделей в графе:

- `flux1-dev-Q5_K_S.gguf`;
- `clip_l.safetensors` и `t5xxl_fp8_e4m3fn_scaled.safetensors`;
- `ae.safetensors`.

Эти файлы, драйверы/CUDA, ComfyUI, ComfyUI-GGUF и лицензии моделей в пакет не входят. Переименовывать узлы, отключать guard или заменять граф ради обхода проверки нельзя. Gateway откажет в генерации, если guard не подтвердил готовность. Непроверенные старые файлы в истории ComfyUI этим кодом задним числом не фильтруются.

В используемом внешнем модераторе работают CPU-модели Qwen3Guard-Gen-0.6B, RuBERT tiny toxicity, Falconsai NSFW и OwenElliott image-safety-classifier-s. Его зависимости включают PyTorch, Transformers, NumPy, Pillow и ONNX Runtime; это отдельное окружение, **не** содержимое `requirements.txt` адаптера. Перенос требует исходников guard/helper/translator, закреплённых версий, проверенных весов и конфигурации той установки. Одних названий моделей недостаточно для воспроизведения её политики. Классификаторы могут ошибаться; ручное согласование публикации в приложении сохраняется.

## Приватные API-контракты

Все содержательные запросы требуют `Authorization: Bearer <key>`. Заголовок не пересылается в ComfyUI или helper. Без ключа доступен лишь минимальный `/health`; он раскрывает название сервиса и готовность. URL с ключом не поддерживаются. Browser Origin запрещён, CORS не включён. Это API для backend, а не для JavaScript браузера.

Поддерживаются как `/v1/...`, так и выбранный префикс плюс `/v1/...` (по умолчанию `/flux-api/v1/...`), поэтому proxy может сохранять путь. При `/flux-demo-api` прежний `/flux-api` в этом экземпляре не обслуживается. Перенаправления к helper запрещены; loopback-запросы обходят системный HTTP proxy.

### Изображение

`POST /v1/images/generations`, `Content-Type: application/json`:

```json
{"model":"flux1-dev","prompt":"Стеклянный завод на рассвете","n":1,"output_format":"png","response_format":"b64_json","size":"1024x1024"}
```

Только `prompt` обязателен. Неизвестные поля отклоняются. Размеры — кратные 64 в диапазоне 256–2048, `n=1`, 20 шагов, PNG, перевод включён. JSON ≤64 КиБ, prompt ≤12000 символов. Успех: `{"created":123,"data":[{"b64_json":"..."}]}`; PNG ≤5 МиБ. Метаданные PNG могут содержать prompt/граф ComfyUI, поэтому изображение следует считать содержащим введённый контекст.

Перед единственным POST в ComfyUI проверяются guard и пустая очередь. Локальный lock разрешает одну генерацию gateway. HTTP 429 означает занятость; новую задачу не ставили. Это ограничение не резервирует очередь от сторонних ComfyUI-клиентов.

**Автоматических повторов нет, idempotency cache нет.** Gateway ждёт до 900 секунд, а настройка backend Mini App по примеру — 300 секунд (его верхний предел 600). Поэтому timeout клиента может наступить при уже принятой задаче. Проверка очереди предотвращает повтор, пока задача ещё выполняется, но не после её завершения. После потери ответа оператор проверяет очередь/историю перед осознанным повтором; повторный POST может создать другое изображение. Этот синхронный контракт не является API восстановления по job ID.

### Текст

`POST /v1/safety/check-text`, JSON **только** `{"texts":["Текст публикации"]}`: 1–16 строк, суммарно ≤12000 символов, без NUL, тело ≤64 КиБ. Проверяются исходящие AI-ответы/черновики, ручные правки и окончательная подпись. Сырьевые факты компании не считаются готовой публикацией.

### Изображение для проверки

`POST /v1/safety/check-image`, сырые bytes с `Content-Type: image/png` или `image/jpeg`, ≤5 МиБ. Разрешены только исправные статические PNG/JPEG, ≤4096² пикселей суммарно. APNG с несколькими кадрами запрещён. Gateway декодирует изображение, преобразует в RGB PNG и передаёт helper; нормализованный PNG ≤24 МиБ. Изображение не сохраняется и не публикуется этим маршрутом.

Оба `/safety/` маршрута возвращают HTTP 200 при полученном решении, включая запрет:

```json
{"allowed":false,"reason":"Материал заблокирован проверкой безопасности.","category":"blocked"}
```

Backend обязан проверить, что `allowed` — именно `true`. На ошибку/timeout/неверный ответ helper — HTTP503 `safety_unavailable`; **материал не отправлять**. Gateway оставляет только `allowed`, `reason`, `category`, не возвращает scores. Helper-контракт: POST `127.0.0.1:8192/check-text` с тем же JSON либо `/check-image` с raw PNG, HTTP200 JSON с bool `allowed` и строками `reason/category`; timeout gateway 90 секунд, ответ ≤64 КиБ.

Другие ошибки: 400 неверный запрос, 401 ключ, 403 Host/Origin, 413 размер, 422 блокировка генерации, 429 занятость, 502 ошибка результата, 503 недоступность. Формат ошибок `{"error":{"message":"...","type":"...","code":"..."}}`. Тела upstream-ошибок, заголовки, промпты и ключи не пишутся в логи gateway и не попадают в его сообщения об ошибках. Решение модератора содержит лишь фиксированную причину, а не исходный текст.

## Разделение публичного Mini App и приватного AI

```text
Браузер/Telegram → публичный HTTPS /mini/ → backend :8766
                                           └→ приватный Tailscale /flux-api/ + Bearer
                                                ├→ ComfyUI 127.0.0.1:8188
                                                ├→ переводчик 127.0.0.1:8190
                                                └→ модератор 127.0.0.1:8192
```

В репозитории `deploy/Caddyfile` проксирует только `/mini/*` в `marketer:8766`, для остальных путей отдаёт 404 (корень перенаправляет в `/mini/`). `app/miniapp/server.py` регистрирует конечный список `/mini/` маршрутов и не имеет общего proxy до ComfyUI. `scripts/run-local-tunnel.py` направляет временный публичный SSH-туннель только в порт Mini App. Статика браузера не содержит обращений к 8188/8190/8192/8193 или `/flux-api`.

**Не публикуйте через Funnel или общий public proxy порты 8188, 8190, 8192 и выбранный порт gateway (8193/8194), а также его префикс.** Сохраните Tailscale Serve приватным; удалённому backend нужен доступ в tailnet и ключ. Публичному браузеру эти доступы не нужны. Проверка исходников подтверждает это разделение; фактические маршруты конкретного развёртывания проверяются оператором отдельно.

Пример `config.example.env` разделяет настройки окружения gateway (`FLUX_GATEWAY_*`) и backend Mini App (`IMAGE_*`, `MODERATION_*`). Настоящие ключи хранятся локально и не выдаются членам команды через frontend. Модерация в live без заданных `MODERATION_API_BASE` и `MODERATION_API_KEY` работает с отказом, а не отключается молча.
